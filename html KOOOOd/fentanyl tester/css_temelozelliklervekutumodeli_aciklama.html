CSS Box Model (Kutu Modeli)

CSS'te her HTML elementi bir kutu olarak düşünülür. Bu kutu dört ana bölümden oluşur: Content (İçerik), Padding (İç Boşluk), Border (Kenarlık) ve Margin (Dış Boşluk). Bu kavramları anlamak CSS'te layout oluşturmanın temelidir.

CONTENT

Dıştan içe: Margin → Border → Padding → Content

Margin (Dış Boşluk)

Margin Nedir?

Margin, bir elementin dışındaki boşluğu kontrol eder. Elementler arası mesafeyi ayarlamak için kullanılır. Margin şeffaftır ve arka plan rengi almaz.

margin: 20px; /* Tüm taraflara 20px */ margin: 10px 20px; /* Üst-Alt 10px, Sağ-Sol 20px */ margin: 10px 20px 30px; /* Üst 10px, Sağ-Sol 20px, Alt 30px */ margin: 10px 20px 30px 40px; /* Üst, Sağ, Alt, Sol */
Margin Örnekleri:
margin: 20px;
margin: 10px 30px;
margin: 5px 15px 25px 40px;
/* Tek yönlü margin */ margin-top: 20px; margin-right: 15px; margin-bottom: 25px; margin-left: 10px;
💡 İpucu: Bir elementi yatayda ortalamak için margin: 0 auto; kullanabilirsiniz (elementin width değeri tanımlı olmalı).
⚠️ Margin Collapse: Dikey olarak yan yana gelen iki elementin margin değerleri birleşir (collapse). Büyük olan margin değeri geçerli olur.

Padding (İç Boşluk)

Padding Nedir?

Padding, bir elementin içeriği ile kenarlığı arasındaki boşluğu kontrol eder. Padding, elementin arka plan rengini alır.

padding: 20px; /* Tüm taraflara 20px */ padding: 10px 20px; /* Üst-Alt 10px, Sağ-Sol 20px */ padding: 10px 20px 30px; /* Üst 10px, Sağ-Sol 20px, Alt 30px */ padding: 10px 20px 30px 40px; /* Üst, Sağ, Alt, Sol */
Padding Örnekleri:
padding: 5px; (Az iç boşluk)
padding: 20px; (Orta iç boşluk)
padding: 30px; (Fazla iç boşluk)
/* Tek yönlü padding */ padding-top: 20px; padding-right: 15px; padding-bottom: 25px; padding-left: 10px;
💡 İpucu: Butonlar, kartlar ve içerik alanları için padding kullanarak içeriğe "nefes aldırın". Bu, tasarımı daha okunaklı hale getirir.

Border (Kenarlık)

Border Nedir?

Border, elementin kenarlarına çizilen çizgidir. Kalınlık, stil ve renk özellikleri vardır.

/* Kısa yol (shorthand) */ border: 2px solid red; /* Kalınlık | Stil | Renk */ /* Ayrı ayrı belirtme */ border-width: 2px; border-style: solid; border-color: red;

Border Stilleri:

solid - Düz çizgi
dashed - Kesikli çizgi
dotted - Noktalı çizgi
double - Çift çizgi
Farklı kenarlara farklı stiller
/* Tek yönlü border */ border-top: 3px solid blue; border-right: 2px dashed green; border-bottom: 4px dotted red; border-left: 5px double purple; /* Yuvarlatılmış köşeler */ border-radius: 10px;
Border Stil Açıklama
solid Düz, kesintisiz çizgi
dashed Kesikli çizgi
dotted Noktalı çizgi
double Çift çizgi
groove 3D oluklu görünüm
ridge 3D kabartma görünüm
inset 3D içe gömülü görünüm
outset 3D dışa çıkık görünüm
none Kenarlık yok
💡 İpucu: border-radius özelliği ile köşeleri yuvarlatarak modern ve şık tasarımlar oluşturabilirsiniz.

Content (İçerik)

Content (İçerik Alanı)

Content, elementin gerçek içeriğinin (metin, resim vb.) bulunduğu alandır. Width ve height özellikleri ile kontrol edilir.

width: 300px; /* Genişlik */ height: 200px; /* Yükseklik */ max-width: 500px; /* Maksimum genişlik */ min-width: 200px; /* Minimum genişlik */ max-height: 400px; /* Maksimum yükseklik */ min-height: 100px; /* Minimum yükseklik */
Content Örnekleri:
200px x 100px
Content Alanı
300px x 150px Content Alanı
Padding ve border bu alana eklenir
⚠️ Box-Sizing: Varsayılan olarak, width ve height değerleri sadece content alanını belirtir. box-sizing: border-box; kullanarak padding ve border'ı da bu boyuta dahil edebilirsiniz.
