CSS Renk Kullanımı

HEX, RGB, HSL, Opacity ve Gradyanlar

Web'in Renkleri

CSS'te renkler, bir web sitesinin duygusunu ve marka kimliğini belirleyen en önemli unsurdur. Metin rengi (color), arka plan rengi (background-color) ve kenarlık rengi (border-color) gibi özelliklerde çeşitli renk formatları kullanabiliriz.

1. Renk Tanımlama Formatları

Yaygın Kullanılan Formatlar

CSS'te renkleri tanımlamanın 4 ana yolu vardır.

Renk İsmi tomato
HEX Kodu #667eea
RGB rgb(72, 187, 120)
HSL hsl(270, 60%, 50%)
/* 1. Renk İsimleri (140+ standart isim) */
color: red;

/* 2. HEX (Hexadecimal - En yaygın) */
/* #RRGGBB (Kırmızı, Yeşil, Mavi) */
color: #ff0000;

/* 3. RGB (Red, Green, Blue) */
/* 0-255 arası değerler */
color: rgb(255, 0, 0);

/* 4. HSL (Hue, Saturation, Lightness) */
/* Renk Tonu, Doygunluk, Parlaklık */
color: hsl(0, 100%, 50%);
💡 İpucu: HSL formatı, bir rengin tonunu değiştirmeden sadece açığını veya koyusunu yapmak istediğinizde (Lightness değerini değiştirerek) çok kullanışlıdır.

2. Saydamlık (Transparency)

Opacity Özelliği vs Alpha Kanalı

Bir elementi şeffaf yapmanın iki yolu vardır, ancak sonuçları farklıdır.

Yöntem Etkisi
opacity: 0.5; Tüm elementi (arka plan + içindeki metin) şeffaf yapar.
rgba(r,g,b, 0.5) Sadece arka plan rengini şeffaf yapar, içindeki metin net kalır.

Opacity: 0.5 (Tüm Kutu)

Metin de silikleşir ve okunması zorlaşır.

RGBA Alpha: 0.5 (Sadece Arka Plan)

Metin %100 opaktır ve net okunur.
/* Tüm element %50 şeffaf */
opacity: 0.5;

/* Sadece renk %50 şeffaf (Alpha kanalı) */
background-color: rgba(255, 0, 0, 0.5);
color: hsla(120, 100%, 50%, 0.3);

3. Gradyanlar (Renk Geçişleri)

Linear Gradient

CSS ile resim dosyası kullanmadan yumuşak renk geçişleri oluşturabilirsiniz. Bu özellik background-image altında tanımlanır.

to right (Sola Doğru)
45deg (45 Derece)
/* Soldan sağa geçiş */
background-image: linear-gradient(to right, #4facfe, #00f2fe);

/* Açılı geçiş */
background-image: linear-gradient(45deg, red, blue);
⚠️ Not: Gradyanlar teknik olarak bir "resim" (image) kabul edilir, bu yüzden background-color yerine background-image veya kısaca background özelliğine yazılır.
