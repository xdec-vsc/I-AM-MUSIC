Neden Responsive?

Responsive (Duyarlı) tasarım, web sitelerinin masaüstü bilgisayarlarda, tabletlerde ve cep telefonlarında düzgün görünmesini sağlar. Sabit pikseller yerine esnek yapılar ve Medya Sorguları (Media Queries) kullanılarak yapılır.

1. Viewport Meta Etiketi

Temel Ayar

Responsive tasarımın çalışması için <head> kısmına mutlaka aşağıdaki viewport meta etiketi eklenmelidir. Bu, mobil tarayıcının sayfayı küçültüp (zoom-out yapıp) göstermesini engeller.

<meta name="viewport" content="width=device-width, initial-scale=1.0">
⚠️ Önemli: Bu satır olmazsa, yazdığınız responsive kodlar mobil cihazlarda düzgün çalışmayacaktır.

2. Media Queries (@media)

Kırılma Noktaları (Breakpoints)

CSS'te @media kuralı, "Eğer ekran genişliği şu kadarsa, bu stili uygula" dememizi sağlar.

/* Varsayılan: Masaüstü stili */
div { background-color: blue; }

/* Ekran 768px veya daha küçükse: */
@media (max-width: 768px) {
  div { background-color: red; }
}
Canlı Test (Pencereyi Daraltın!)

Aşağıdaki kutu, tarayıcı penceresini daralttığınızda renk ve yazı değiştirecektir.

💡 İpucu: Genellikle Mobile First (Önce Mobil) yaklaşımı kullanılır. Yani önce mobil kodları yazılır, sonra min-width kullanılarak masaüstü için genişletilir.

3. Esnek Görseller (Fluid Images)

max-width: 100%

Büyük resimlerin küçük ekranlardan taşmasını engellemek için resimlere esneklik kazandırmalıyız.

img {
  max-width: 100%;
  height: auto;
}
