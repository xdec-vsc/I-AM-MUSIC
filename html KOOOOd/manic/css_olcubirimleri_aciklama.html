Ölçü Birimleri Nedir?

CSS'te elementlerin boyutlarını, aralıklarını ve konumlarını belirlemek için çeşitli ölçü birimleri kullanırız. Bu birimler iki ana kategoriye ayrılır: Mutlak Birimler (sabit boyutlar) ve Göreceli Birimler (değişken boyutlar).

Mutlak Ölçü Birimleri

Pixel px

En yaygın kullanılan birimdir. Ekrandaki bir piksel noktasını temsil eder. Sabit bir boyut sağlar ve farklı cihazlarda aynı görünür (yoğunluk farkları hariç).

div {
width: 100px;
height: 50px;
margin: 20px;
padding: 10px;
}
Görsel Örnek:
10px x 10px
50px x 50px
100px x 100px
💡 İpucu: Pixel, kesin boyutlar için idealdir. Kenarlıklar, gölgeler ve küçük aralıklar için tercih edilir.

Diğer Mutlak Birimler

Birim Açıklama Kullanım
cm Santimetre Genellikle yazdırma için
mm Milimetre Yazdırma için
in İnç (1in = 2.54cm) Yazdırma için
pt Point (1pt = 1/72 inç) Font boyutları için
pc Pica (1pc = 12pt) Tipografi için
⚠️ Dikkat: Bu birimler genellikle yazdırma (print) medyası için kullanılır. Web tasarımında nadiren tercih edilir.

Göreceli Ölçü Birimleri

Yüzde %

Üst (parent) elementin boyutuna göre hesaplanır. Responsive tasarım için çok kullanışlıdır.

.child {
width: 50%; /* Üst elementin yarısı */
height: 100%; /* Üst elementin tamamı */
}
Görsel Örnek:
Üst Element (400px x 200px)
50% x 50%
100% x 30%
💡 İpucu: Yüzde birimleri, flexible ve responsive layout'lar için mükemmeldir.

EM em

Üst elementin font boyutuna göre hesaplanır. 1em = üst elementin font boyutu.

.parent {
font-size: 16px;
}

.child {
font-size: 2em; /* 32px (16px x 2) */
padding: 1em; /* 32px (kendi font boyutu) */
}
Görsel Örnek:
Bu metin 20px boyutunda
Bu metin 1.5em (30px) boyutunda
⚠️ Dikkat: EM birimleri iç içe elementlerde bileşik etki gösterir (compound effect). Her seviyede üst elementin boyutuna göre hesaplanır.

REM rem

Root elementin (html) font boyutuna göre hesaplanır. 1rem = kök elementin font boyutu (varsayılan 16px).

html {
font-size: 16px; /* Root boyutu */
}

.element {
font-size: 1.5rem; /* 24px (16px x 1.5) */
margin: 2rem; /* 32px (16px x 2) */
}
Görsel Örnek:
1rem boyutunda metin (16px)
2rem boyutunda metin (32px)
💡 İpucu: REM, EM'den daha tutarlıdır çünkü her zaman root elemana göre hesaplanır. Modern projelerde tercih edilir.

Viewport Width vw

Tarayıcı penceresinin genişliğinin yüzdesi. 1vw = viewport genişliğinin %1'i.

.full-width {
width: 100vw; /* Tam ekran genişliği */
}

.half-width {
width: 50vw; /* Ekranın yarısı */
}
Görsel Örnek:
Bu element 50vw genişliğinde

Tarayıcı pencerenizi küçültüp büyüterek etkiyi görebilirsiniz.

Viewport Height vh

Tarayıcı penceresinin yüksekliğinin yüzdesi. 1vh = viewport yüksekliğinin %1'i.

.hero-section {
height: 100vh; /* Tam ekran yüksekliği */
}

.half-screen {
height: 50vh; /* Ekranın yarısı */
}
Görsel Örnek:
Bu element 20vh yüksekliğinde
💡 İpucu: vw ve vh, tam ekran hero bölümler, landing page'ler ve responsive tasarımlar için mükemmeldir.

Diğer Viewport Birimleri

Birim Açıklama
vmin vw ve vh'den küçük olanı (viewport'un küçük boyutu)
vmax vw ve vh'den büyük olanı (viewport'un büyük boyutu)
svw/svh Small viewport (mobil için optimize)
lvw/lvh Large viewport (maksimum boyut)
dvw/dvh Dynamic viewport (dinamik olarak ayarlanan)

CH (Karakter Genişliği) ch

"0" (sıfır) karakterinin genişliği kadar. Metin tabanlı layout'lar için idealdir.

.paragraph {
width: 60ch; /* Yaklaşık 60 karakter genişliği */
/* Okunabilir satır uzunluğu için ideal */
}
💡 İpucu: Optimal okuma deneyimi için paragrafları 45-75ch genişliğinde tutun.

EX (x-height) ex

Küçük harf "x" karakterinin yüksekliği kadar. Font metriklerine dayalı düzenlemeler için kullanılır.

.subscript {
font-size: 0.5ex;
}

Hangi Birimi Ne Zaman Kullanmalı?

Font Boyutları

✅ rem - En iyi seçim

✅ em - Bileşenler için

⚠️ px - Kaçının

Genişlik/Yükseklik

✅ % - Responsive için

✅ vw/vh - Tam ekran için

✅ px - Sabit boyutlar için

Margin/Padding

✅ rem - Tutarlılık için

✅ em - Font'a göre

✅ px - Küçük değerler için

Kenarlıklar

✅ px - En iyi seçim

⚠️ Diğer birimler nadiren kullanılır

Medya Sorguları

✅ em/rem - Erişilebilirlik için

⚠️ px - Geleneksel yöntem

Metin Satır Uzunluğu

✅ ch - İdeal seçim

✅ % - Alternatif

⚠️ Önemli Notlar:
  • Modern web tasarımında responsive ve erişilebilir siteler için rem ve % tercih edilir
  • Pixel kullanımı azalıyor, ancak kenarlıklar ve gölgeler gibi küçük detaylar için hala uygun
  • Viewport birimleri (vw, vh) mobil uyumlu tasarımlar için çok güçlü
  • Em ve rem arasında tercih yaparken, genellikle rem daha tutarlı sonuçlar verir
💡 Best Practice: Bir projede tutarlı bir ölçü birimi sistemi kullanın. Örneğin: font boyutları için rem, aralıklar için rem/em, container genişlikleri için % veya max-width kombinasyonu.
