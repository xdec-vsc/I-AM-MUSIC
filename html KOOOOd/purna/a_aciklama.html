HTML <a> Etiketi (Anchor - Bağlantı)

Temel Kullanım

<a> etiketi, HTML'de hyperlink (köprü) oluşturmak için kullanılır. Kullanıcıların bir sayfadan başka bir sayfaya, belgeye veya konuma gitmesini sağlar.

<a href="adres">Görünen Metin</a>

Önemli Özellikler (Attributes)

Özellik Açıklama
href Gidilecek adresi belirtir (en önemli özellik)
target Bağlantının nerede açılacağını belirtir
title Fare üzerine geldiğinde gösterilecek açıklama
download Dosyanın indirilmesini sağlar

Örnekler

1. Basit Bağlantı

<a href="https://www.google.com">Google'a Git</a>

Çalışan Örnek: Google'a Git

2. Yeni Sekmede Açma (target="_blank")

<a href="https://www.wikipedia.org" target="_blank">Wikipedia (Yeni Sekme)</a>

Çalışan Örnek: Wikipedia (Yeni Sekme)

3. Email Bağlantısı (mailto:)

<a href="mailto:ornek@email.com">Email Gönder</a>

Çalışan Örnek: Email Gönder

4. Telefon Bağlantısı (tel:)

<a href="tel:+905551234567">Ara: +90 555 123 45 67</a>

Çalışan Örnek: Ara: +90 555 123 45 67

5. Aynı Sayfada Bölüme Gitme (Anchor Link)

<a href="#alt-bolum">Alta Git</a>

<h2 id="alt-bolum">Alt Bölüm</h2>

Çalışan Örnek: Test Bölümüne Git

6. Title Özelliği ile Açıklama

<a href="https://www.github.com" title="Kod paylaşım platformu">GitHub</a>

Çalışan Örnek: GitHub (Farenizi üzerine getirin)

💡 Önemli Notlar

  • href olmadan <a> etiketi çalışmaz
  • target="_blank" kullanırken güvenlik için rel="noopener noreferrer" eklemek önerilir
  • Bağlantı metni açıklayıcı olmalı ("tıklayın" yerine "ürün sayfasına git" gibi)
  • Ziyaret edilmiş linkler farklı renkte görünür (visited durumu)

Target Özelliği Değerleri

Değer Açıklama
_blank Yeni pencere veya sekmede açar
_self Aynı pencerede açar (varsayılan)
_parent Üst frame'de açar
_top Tüm frame'leri kaldırıp tam pencerede açar

✓ Özet

<a> etiketi web'in temel taşıdır. Sayfalar arası gezinmeyi, email göndermeyi, telefon aramayı ve aynı sayfa içinde hareketliliği sağlar. Her zaman anlamlı ve erişilebilir bağlantılar oluşturun!
