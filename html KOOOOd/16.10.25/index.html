HTML Form Elemanları

1. <input> Elemanı

Tanım: Form tarafından en çok kullanılan eleman, metin, şifre, sayı, tarih ve daha bir giriş verisi için kullanılır.
Söz Dizimi: <input type="tür" name="ad" placeholder="ipucu">

Text Input ( Metin Girişi )

Email Input ( Mail Girişi )

Password Input ( Şifre Girişi )

Number Input ( Sayı Girişi )

Date Input ( Tarih Girişi )

Checkbox ( Çoklu Seçim )




Radio Button ( Tek Seçim )




Dosya İnput






2. <textarea> Elemanı

Tanım: Çok satırlı metin girişi için kullanılır. Yorum, adres, mesaj, açıklama gibi uzun metinler için idealdir.
Söz Dizimi: <textarea name="ad" rows="satır" cols="sütun"></textarea>

TextArea ( Adres Girişi )


3. <select> Elemanı

Tanım: Açılır liste oluşturur. Kullanıcının önceden tanımlı seçenekler arasından bir seçim yapmasını sağlar
Söz Dizimi: <select name="ad" > <option value="tr">Türkiye</option> </select>

select ( İller Seçimi Girişi )

4. <button> Elemanı

Tanım: Tıklanabilir bi eleman oluşturmayı sağlar. Form göndermek, sayfayı yenilemek ve JS kod çalıştırmak için kullanılır.
Söz Dizimi: <button type="tğr">Düğme Metin</button>
